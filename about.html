LUNAR LANDER — TOURNAMENT EDITION

Who can stick the landing?

Four pilots share this pad — and you can be one of them. Fly solo, drop into a 1v1 or 2v2 best-of-three, or run the four-pilot Cup. Same sky, same hazards, one question: who sticks the landing?

Every pilot flies the identical course and the identical hazard timeline

Same seed, same step, same sky. When a hazard fires, it fires for every pilot at the same physics step — so a match is won on skill, not luck.

From a course project to a cabinet

This cabinet runs a pilot trained in the Hugging Face Deep RL Course (Unit 1 hands-on) and published by seekdepth. We play it live in your browser — alongside four more pilots imported from other builders. See the default pilot's checkpoint.

01 / PILOT MODES

Four ways to fly.

Single Player is the training corner: fly it yourself, let the AI fly solo, or grab an Autopilot + Override stick. Tournament runs Versus (1v1), Doubles (2v2), or the four-pilot Cup — score, round wins, and clean landings stack up until one pilot takes the crown.

02 / THE PILOTS

Eight readings in. One move out.

Every pilot reads the same eight cockpit readings and picks one move: coast, tilt left, fire the main engine, or tilt right. Tournament hazards — Sensor Glitch, Faulty Thrusters, Low/Heavy Gravity, Wind Shear — are armed per match or per round, and they strike every pilot on the same physics step from one shared seed. The gauges always show your true state.

How the cabinet is built

The environment and physics run in Python through Pyodide 0.23.4. PyPyBox2D supplies the pure-Python rigid-body solver; a small Gymnasium-compatible shim provides the local environment interface. JavaScript draws the canvas, handles keyboard input, and runs the pilots’ inference with ONNX Runtime Web 1.19.2 on its WebAssembly CPU backend.

The port follows the classic LunarLander-v2 observation and reward structure but is not bit-for-bit identical to the native Box2D environment. It uses PyPyBox2D’s older Box2D 2.1-era solver and adds a settled-contact landing completion rule.

Reference material: the LunarLander-v2 environment, the adapted LunarLander source, Stable-Baselines3 PPO, Pyodide 0.23-series deployment, and ONNX Runtime Web.

Physics engine: PyPyBox2D by Ken Lauer, from the 2.1-r331 PyPI source release. The wheel retains the upstream zlib license notice.
